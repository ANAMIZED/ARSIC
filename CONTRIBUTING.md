# Contributing to ARSIC

Thank you for your interest.

1. Read `AGENTS.md` — it is the coding-agent contract.
2. Run the core test suite before opening a PR: `python3 -m unittest discover -s tests`.
3. Prefer small, focused PRs that strengthen invariants or documentation.
4. Do not introduce network dependencies into the core package or the 66 core tests.
5. Update `docs/COMPLIANCE_MATRIX.md` when you change a mapped requirement or substitution.
6. Keep the privilege ladder and human gates intact.

By contributing you agree that your contributions are licensed under the Apache-2.0 license.
